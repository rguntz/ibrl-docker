HOW IT WORKS - HIGH LEVEL:
═══════════════════════════════════════════════════════════════════════════════

TRAINING FLOW:
  Episode collected in memory
      ↓
  Episode step tracked: obs, action, reward, terminal
      ↓
  Episode completes
      ↓
  _save_current_episode_to_disk() called
      ↓
  Episode converted to HDF5 format
      ↓
  Saved to: save_dir/replay_persist/[episode_type]/
      ↓
  Metadata updated


CRASH RECOVERY FLOW:
  Training crashes (program exits)
      ↓
  All completed episodes on disk ✅
      ↓
  User restarts: python train_rl_trossen_real.py --config config.yaml
      ↓
  Workspace.__init__() called
      ↓
  _setup_replay() called
      ↓
  _recover_replay_from_disk() AUTO-CALLED ◄─── KEY!
      ├─ Detect saved episode files
      ├─ Load each episode from HDF5
      ├─ Reconstruct in replay buffer
      └─ Report statistics
      ↓
  Training resumes with all recovered episodes + checkpoint


STORAGE FORMAT:
═══════════════════════════════════════════════════════════════════════════════

Directory structure:
  save_dir/replay_persist/
  ├─ rl_episodes/         ← RL training episodes
  ├─ bc_episodes/         ← BC demonstrations
  ├─ warmup_episodes/     ← Warmup phase episodes
  └─ replay_metadata.json ← Tracking metadata

File format (HDF5):
  episode_000001.h5
  ├─ Attributes: episode_type, success
  ├─ obs/ - Observation data
  ├─ actions - Action trajectory
  ├─ rewards - Reward trajectory
  └─ terminals - Terminal flags

WHAT HAPPENS IN DIFFERENT CRASH SCENARIOS:
═══════════════════════════════════════════════════════════════════════════════

Power Loss Mid-Episode:
  ├─ Episode not completed: NOT saved
  ├─ Previous episodes: ALL saved ✅
  └─ Recovery: Load all previous, restart current

OOM Error:
  ├─ Current episode: Depends on crash timing
  ├─ Previous episodes: ALL saved ✅
  └─ Recovery: Load all previous, restart current

Network Disconnect:
  ├─ Local episodes: ALL saved ✅
  └─ Recovery: Load all, continue offline

Process Termination (Ctrl+C):
  ├─ If at episode boundary: ALL saved ✅
  ├─ If mid-episode: Previous episodes saved ✅
  └─ Recovery: Load all previous episodes

System Reboot:
  ├─ All episodes: SAVED to persistent disk ✅
  └─ Recovery: Load all, continue training
